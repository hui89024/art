# 剪艺首页重设计方案

## 设计理念

将传统剪纸艺术的**装饰性、层次感、色彩丰富**特点融入现代网页设计，摒弃极简风格，打造沉浸式的东方美学体验。

---

## 核心设计策略

### 1. 风格定位：Motion-Driven + 东方奢华

**Motion-Driven 特点：**
- 丰富的滚动触发动画
- 视差滚动效果（3-5层）
- 流畅的页面过渡（300-400ms）
- 微交互细节
- 叙事性的内容展开

**东方奢华特点：**
- 深色背景 + 金色/红色点缀
- 传统纹样装饰元素
- 层叠的视觉层次
- 丰富的质感（渐变、阴影、光效）

### 3. 视觉层次增强

#### 3.1 Hero区域
- **当前**：简洁轮播图
- **重设计**：
  - 全屏沉浸式轮播（100vh）
  - 添加视差效果（前景剪纸图案 + 中景内容 + 背景纹理）
  - 金色粒子飘落动画
  - 毛笔字体标题 + 金色描边
  - 渐变遮罩（从透明到深色）

#### 3.2 作品展示区
- **当前**：3列卡片网格
- **重设计**：
  - 卡片添加金色边框 + 阴影光晕
  - Hover时卡片上浮 + 金光扩散效果
  - 背景添加淡淡的剪纸纹样水印
  - 系列标签使用印章样式
  - 添加"更多作品"的装饰性分隔线（传统云纹图案）

#### 3.3 工艺技术区
- **当前**：FeatureGrid组件
- **重设计**：
  - 每个特性卡片添加独特的剪纸图标背景
  - 滚动进入时逐个淡入 + 旋转效果
  - 添加连接线条（模拟剪纸的镂空连接）
  - 背景使用深色渐变 + 金色光斑

#### 3.4 数字生态区
- **当前**：左右分栏布局
- **重设计**：
  - 添加交错视差效果
  - 手机/电脑模型周围添加环绕的剪纸纹样动画
  - 背景使用径向渐变（从中心金色到边缘深色）
  - 添加"数字化传承"的装饰性标题框

#### 3.5 宣言区
- **当前**：森林背景 + 文字
- **重设计**：
  - 背景改为传统剪纸作品的模糊大图
  - 文字使用书法字体 + 金色
  - 添加印章元素
  - 周围环绕飘动的剪纸碎片动画

### 4. 装饰性元素

#### 4.1 页面装饰
- 页面四角添加传统窗花纹样装饰
- 章节分隔使用云纹/回纹图案
- 滚动条自定义为金色细线
- 鼠标指针添加剪纸图案跟随效果（可选）

#### 4.2 动效增强
- 页面加载时的剪纸展开动画
- 滚动时的视差层次移动
- 卡片Hover的金光扫过效果
- 按钮点击的涟漪扩散（金色）
- 背景的微妙粒子漂浮

#### 4.3 纹理叠加
- 纸张质感纹理（subtle）
- 金箔质感（在金色元素上）
- 墨迹晕染效果（在深色背景上）

### 5. 字体系统

```css
/* 标题 - 使用书法感字体 */
--font-heading: 'ZCOOL XiaoWei', 'Ma Shan Zheng', serif;

/* 正文 - 保持可读性 */
--font-body: 'Noto Sans SC', 'PingFang SC', sans-serif;

/* 装饰性文字 */
--font-decorative: 'ZCOOL KuaiLe', 'Liu Jian Mao Cao', cursive;
```

### 6. 响应式策略

- **桌面端（>1024px）**：完整动效 + 视差效果
- **平板端（768-1024px）**：简化视差，保留主要动效
- **移动端（<768px）**：禁用视差，保留淡入动效，优化触摸交互

## 技术实现要点

### 1. 动画库
- 继续使用 `animejs` 作为核心动画引擎
- 添加 `Intersection Observer` 用于滚动触发
- 使用 `transform` 和 `opacity` 确保性能

### 2. 性能优化
- 视差效果使用 `will-change: transform`
- 装饰性图片使用 WebP 格式
- 动画帧率控制在 60fps
- 提供 `prefers-reduced-motion` 降级方案

### 3. 无障碍
- 所有装饰性元素添加 `aria-hidden="true"`
- 保持键盘导航流畅
- 确保文字对比度 ≥4.5:1
- 动画可通过系统设置禁用
