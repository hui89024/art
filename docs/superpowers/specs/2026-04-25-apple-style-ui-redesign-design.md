# Apple 风格全站 UI 重设计规格（A+B 混合）

- 日期：2026-04-25
- 项目：剪艺数字艺术平台
- 范围：全站六个页面（Home / Collectibles / Events / AppDownload / Contact / PatternLibrary）
- 约束：不删除任何现有功能；双端同优先；视觉冲击优先；重做配色但保留传统文化气质

## 1. 目标与非目标

### 1.1 目标
1. 首屏 3 秒内形成“眼前一亮”的高端视觉冲击。
2. 建立统一的现代化设计语言，消除旧式网页观感。
3. 显著提升动效质量与节奏层次，避免单调重复。
4. 保持全部现有功能与业务流程可用，确保零功能回归。
5. 桌面端与移动端同时达到可用与美观标准。

### 1.2 非目标
1. 不修改后端 API 协议与鉴权语义。
2. 不新增与本次视觉改版无关的业务功能。
3. 不进行与本次目标无关的大规模架构重写。

## 2. 设计方向（A+B 混合）

### 2.1 总体方向
采用 **Apple-Style Cinematic（A）** 作为主线，融合 **Heritage Premium（B）** 的文化表达：
- A：极简留白、大标题、叙事滚动、强对比首屏。
- B：剪纸文化元素（红、纹样、纹理）点睛式融入。

### 2.2 核心原则
1. **冲击优先**：首屏必须具备明确视觉锚点与主行动路径。
2. **统一优先**：全站在颜色、字体、间距、卡片、按钮、动效参数上统一。
3. **点睛而非堆砌**：文化元素克制使用，避免信息噪音。
4. **功能不变**：所有既有交互与数据流程保持一致。

## 3. 视觉系统规范

### 3.1 色彩系统（重做并保留文化气质）
- `Brand Red`：品牌主红，用于关键 CTA 与视觉焦点。
- `Ink Black`：高端深色文本与深色背景。
- `Porcelain White`：主背景留白。
- `Jade Gray`：中性色分层。
- `Gold Accent`：少量强调（徽章、稀缺状态）。

使用规则：
- 红色仅用于“需要用户动作或关注”的节点。
- 强调色总面积受控，避免满屏高饱和导致疲劳。

### 3.2 字体与层级
- Hero 标题（桌面）：56–72 区间，字重中高，紧凑行高。
- 正文：16–18 为主；移动端不低于 15。
- 每屏视觉主层级上限 3 层（主标题 / 解释 / 行动）。

### 3.3 栅格与间距
- 桌面：12 栅格，控制最大内容宽度，强化留白。
- 移动：4 栅格，纵向节奏统一。
- 间距 token：采用统一倍数节拍体系（如 8px 基准）。

### 3.4 组件外观基线
- 卡片：中大圆角、轻边框、弱阴影、可选轻玻璃质感。
- 按钮：主按钮高对比实体样式；次按钮低干扰线框样式。
- 导航：强化品牌与关键路径，收敛噪声入口。

## 4. 页面级改版蓝图（六页）

### 4.1 HomeView
- 全屏 Hero：大标题 + 品牌宣言 + 单主 CTA。
- 三段滚动叙事区：承载品牌价值与核心差异。
- 页面收口：通向其余页面的高质感入口卡片。
- 移动端：压缩文案密度，保留首屏冲击与 CTA 可达性。

### 4.2 CollectiblesView
- 首屏建立“藏品画廊”视觉语境与筛选入口。
- 列表改为高级栅格，hover 聚焦反馈增强浏览愉悦。
- 详情层级重排：先价值信息，后补充说明。
- 移动端筛选抽屉化，卡片密度自适应。

### 4.3 EventsView
- 首屏展示活动主 KV 与状态标签（进行中/即将）。
- 中段采用时间轴 + 活动卡片混合叙事。
- 关键活动卡片加入轻入场与聚焦反馈。
- 移动端纵向时间轴精简，状态信息优先可读。

### 4.4 AppDownloadView
- 首屏“设备展示 + 核心卖点 + 下载动作”三位一体。
- 功能亮点分区采用 1 图 + 1 价值句的高密度表达。
- 下载区域统一按钮层级与二维码组合。
- 移动端确保下载入口在首屏可触达。

### 4.5 ContactView
- 页面头部品牌化，不再仅表单直出。
- 联系方式、合作入口、社媒信息分组模块化。
- 表单控件统一质感样式，反馈状态明确。
- 移动端优先展示高频联系方式与快速动作。

### 4.6 PatternLibraryView（鉴权）
- 登录前：品牌化引导，不使用生硬拦截式呈现。
- 登录后：搜索/筛选/分页/详情重组为“探索工作台”。
- 纹样卡片突出视觉主体，弱化噪声信息。
- 移动端搜索筛选吸顶，详情优先全屏抽屉。

## 5. 动效系统设计

### 5.1 三层动效模型
- L1 页面级：首屏入场、章节切换、滚动分镜（制造冲击）。
- L2 模块级：内容分组 reveal、卡片错峰（制造节奏）。
- L3 微交互级：按钮/卡片/表单反馈（制造精致感）。

### 5.2 参数基线
- 页面入场：0.7s–1.1s
- 卡片错峰：60–120ms
- 微交互：120–220ms
- 主叙事缓动：`easeOutExpo` / `easeOutQuart`
- 微交互缓动：`easeOutCubic`
- 滚动触发阈值：元素可见 20%–30%

### 5.3 六页差异化镜头语言
- Home：电影分镜式滚动叙事（最强冲击）
- Collectibles：画廊错峰与聚焦放大
- Events：时间流动过渡
- AppDownload：设备演示连贯切换
- Contact：轻动效、低干扰
- PatternLibrary：效率优先、顺滑反馈

### 5.4 性能与可访问性约束
- 关键动效优先，非关键动效延迟加载。
- 移动端优先 transform/opacity，减少高成本特效。
- 支持 `prefers-reduced-motion` 降级。
- 不允许以动效牺牲交互响应。

## 6. 工程落地架构

### 6.1 改造边界
- 仅改视觉层、交互层、动效层。
- 路由、鉴权、接口语义保持不变。

### 6.2 设计令牌体系
在 `tailwind.config.js` 与 `src/assets/index.css` 建立统一 token：
- `color/*`
- `space/*`
- `radius/*`
- `shadow/*`
- `motion/*`

页面与组件禁止新增散落魔法值，统一引用 token。

### 6.3 组件改造焦点
- `src/components/NavBar.vue`
- `src/components/Carousel.vue`
- `src/components/PhoneAnimation.vue`
- `src/components/LaptopAnimation.vue`
- 抽象建议：`SectionHero` / `FeatureGrid` / `CTACluster`

### 6.4 页面执行顺序
1. `src/views/HomeView.vue`
2. `src/views/CollectiblesView.vue`
3. `src/views/EventsView.vue`
4. `src/views/AppDownloadView.vue`
5. `src/views/ContactView.vue`
6. `src/views/PatternLibraryView.vue`

## 7. 风险与控制

1. 动效过载导致性能下降  
   - 控制：分层预算、移动端降级、首屏优先。
2. 统一过度导致页面同质化  
   - 控制：统一骨架 + 差异化镜头语言。
3. 改版周期拉长导致返工  
   - 控制：按页验收，先静态视觉后动效叠加。

## 8. 验收标准

1. 任一页面打开 3 秒内呈现显著高级感与视觉冲击。
2. 六页视觉语言一致但不雷同。
3. 双端均达到“首屏惊艳 + 操作顺滑”。
4. 零功能缺失，零关键交互回归。
5. 动效主观观感提升且关键路径无性能退化。

## 9. 交付物

1. 一套统一设计令牌规范（颜色、间距、圆角、阴影、动效）。
2. 六个页面的新版视觉与交互规范。
3. 动效分层参数表与降级策略。
4. 分页实施顺序与验收清单。
