# 活动页面轮播大图设计

## 概述

将活动页面（EventsView）上方的单活动展示卡片改造为全宽图片轮播组件，底部叠加半透明信息卡片，保留下方活动网格卡片。

## 布局

```
┌──────────────────────────────────────┐
│           特色活动（Hero区）           │
│                                      │
│    ┌────────────────────────────┐    │
│    │                            │    │
│    │     活动大图（全宽轮播）      │    │
│    │     aspect-ratio: 16/7     │    │
│    │                            │    │
│    │  ┌──────────────────────┐  │    │
│    │  │ 日期  标题  描述  →  │  │    │
│    │  └──────────────────────┘  │    │
│    │        ● ● ○ ○             │    │
│    └────────────────────────────┘    │
│                                      │
│    ← →  左右箭头悬浮在图片两侧        │
│                                      │
├──────────────────────────────────────┤
│        活动卡片网格（保留现有）         │

└──────────────────────────────────────┘
```

## 核心交互

| 功能 | 说明 |
|------|------|
| 自动轮播 | 默认 5 秒切换，鼠标悬停暂停 |
| 左右箭头 | 悬浮在图片左右两侧，点击切换 |
| 指示点 | 底部居中，点击可跳转到指定活动 |
| 信息卡 | 半透明毛玻璃卡片，叠加在图片底部 |
| 过渡动画 | 图片淡入淡出 + 信息卡上滑入场 |
| 点击行为 | 点击图片或信息卡打开活动弹窗（复用 EventModal） |

## 组件结构

### EventCarousel.vue（新增）

- Props: `events` (Array)
- 自动轮播逻辑：`setInterval` + 鼠标悬停暂停
- 图片过渡：CSS `opacity` transition
- 信息卡过渡：CSS `transform` + `opacity`
- 箭头/指示点内置
- Emits: `select` (点击活动时触发，用于打开 EventModal)

### EventsView.vue（修改）

- 移除 featured event 双栏卡片
- 移除导航控制区（箭头 + 指示点）
- 引入 `EventCarousel` 替代
- 保留下方网格卡片 + EventModal 弹窗

## 样式规范

- 轮播容器：`rounded-2xl overflow-hidden`
- 信息卡：`bg-white/80 backdrop-blur-xl` 毛玻璃效果
- 箭头按钮：复用现有 `glass-button` 样式
- 指示点：复用现有 `indicator` 样式
- 圆角、阴影与现有 glass-card 风格一致

## 技术细节

- 不引入额外依赖，使用 CSS transition + setInterval
- `onUnmounted` 清理定时器
- `@mouseenter` / `@mouseleave` 控制暂停/恢复
- 图片使用 `v-show` 而非 `v-if`，避免重复加载
