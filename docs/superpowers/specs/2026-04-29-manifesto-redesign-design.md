# 剪艺宣言区重新设计规范

> 日期：2026-04-29
> 状态：已批准
> 设计方向：晨光纸韵 - 明亮温暖风格

---

## 1. 设计目标

将首页宣言区从现有的暗调深色风格，转变为明亮温暖的"晨光纸韵"风格，营造阳光下剪纸工坊的温馨氛围。

### 核心改变
- **配色**：从深黑/深棕 → 淡米色/暖白
- **文字**：从浅灰 → 深棕/红棕
- **装饰**：从红色系 → 金色系
- **文案**：从哲学抽象 → 温暖诗意

---

## 2. 色彩系统

### 2.1 主色调

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#FAF5EF` | 淡米色，宣纸般的温暖底色 |
| 主文字 | `#5D4037` | 深棕，温润有力，阅读舒适 |
| 强调文字 | `#8B4513` | 红棕，用于核心宣言诗句 |
| 渐变文字 | `#8B4513 → #D2691E → #8B4513` | 红棕到巧克力色的温暖渐变 |
| 装饰线/图标 | `#B8860B` | 暗金，鎏金质感，低调奢华 |
| 标签文字 | `#A0522D` | 赭石，"剪艺宣言"标签 |
| 副文本 | `#795548` | 中棕，哲学阐述段落 |

### 2.2 光晕效果

| 位置 | 渐变 | 效果 |
|------|------|------|
| 左侧光晕 | `#DEB887 → transparent` | 暖黄到透明，像晨光 |
| 右侧光晕 | `#D2B48C → transparent` | 浅棕到透明，柔和过渡 |
| 中心光晕 | `#F5DEB3 → #DEB887 → #F5DEB3` | 小麦色渐变，温暖中心 |

## 3. 全新文案

### 3.1 核心宣言（三行诗）

```
纸，是时光的信笺。
刀，是心意的画笔。
每一次裁剪，都是与美好的相遇。
```

### 3.2 哲学阐述段落

```
在剪艺的世界里，
一把剪刀，一张红纸，
便能剪出四季的风景、千年的祝福。

我们相信，
传统不是尘封的记忆，
而是流淌在指尖的温度。

每一刀落下，
都是匠心与时光的对话；
每一幅窗花，
都是送给生活的礼物。
```

### 3.3 印章组内容

保留印章概念，改为小型篆刻图标：

| 字 | 词 | 寓意 |
|----|-----|------|
| 剪 | 剪影 | 捕捉光影的艺术 |
| 纸 | 纸韵 | 纸上生花的魔法 |
| 匠 | 匠心 | 专注与热爱 |
| 心 | 心意 | 每一刀的温度 |

## 4. 装饰元素

### 4.1 云纹装饰

- 保持现有云纹SVG形状
- 颜色调整为：`rgba(184, 134, 11, 0.15)` (半透明金色)

### 4.2 分隔线

- 保持渐变透明度设计
- 颜色调整为：`#B8860B → transparent` (金色渐变)

### 4.3 滚动指示器

- 保持胶囊形外框 + 弹跳小圆点设计
- 外框颜色：`#B8860B` (暗金)
- 小圆点颜色：`#8B4513` (红棕)

### 4.4 背景纹理

- 保持窗花图案叠加
- 透明度调整为：`opacity: 5%` (在浅色背景上更易察觉)

### 4.5 印章样式

新设计的篆刻图标：
- 形状：圆形或方形小印章
- 边框：`1.5px solid #B8860B`
- 内部文字：篆书风格，颜色 `#8B4513`
- Hover效果：边框变为 `#A0522D`，轻微放大 `scale(1.05)`
- 旋转角度：`0度` (正立放置，更稳重)

## 5. 动画系统

### 5.1 序列入场动画

保持现有参数不变：
- 元素数量：13个
- 总时长：约1.2秒
- 间隔：每个元素100ms
- 动画类型：`fade-in` 和 `slide-up`
- 触发方式：IntersectionObserver (阈值0.15)
- 无障碍支持：`prefers-reduced-motion`

### 5.2 印章交互

- Hover过渡：`250ms ease-out`
- 边框颜色变化：`#B8860B → #A0522D`
- 缩放效果：`scale(1.05)`
