# 首页区域背景重新设计 — 设计规格

> 创建时间：2026-04-30
> 状态：设计完成，待实施

---

## 1. 设计概述

### 1.1 目标

重新设计首页三个区域（核心作品、剪艺宣言、剪艺应用）的背景，解决当前背景单调、氛围不足、区域间区分度不够的问题。移除全局 ParallaxBackground，让每个区域拥有独立且强烈的视觉身份。

### 1.2 设计方向

**路线：** 方案 A（自然意境）+ 方案 B（纸艺材质）融合

| 区域 | 主题 | 视觉概念 |
|------|------|----------|
| 核心作品 | 宣纸展厅 | 柔和光线洒在宣纸上，作品悬浮其上 |
| 剪艺宣言 | 纸雕光影 | 阳光穿透镂空纸面，投下细腻的光影花纹 |
| 剪艺应用 | 锦缎织造 | 浅色织锦在暖光下展开，金丝银线交织精密纹样 |

### 1.3 设计约束

- **全浅色系：** 不使用深色背景，保持明亮温暖的调性
- **大胆差异化：** 三个区域视觉身份截然不同，滚动时产生"移步换景"的惊喜感
- **性能优先：** 背景效果不增加超过 100ms 加载时间，滚动保持 60fps
- **无障碍支持：** `prefers-reduced-motion` 下禁用动效，确保文字对比度达标

## 2. 移除全局背景

### 2.1 操作

- 从 `HomeView.vue` 中移除 `<ParallaxBackground>` 组件及其 import
- `ParallaxBackground.vue` 和 `useParallax.js` 文件保留（可能其他页面或未来需要）
- `<main>` 容器的 `bg-transparent` 改为不设背景或设为最浅区域的底色作为 fallback

### 2.2 影响

- 全页默认无背景色，各区域自行控制
- 未覆盖区域（如 Footer、SectionHero、Carousel）需补充 `bg-paper-base` 或类似浅色底作为 fallback
- `<main>` 容器设置 `bg-[#f8f4ef]` 作为全页 fallback 底色，确保无区域遗漏

## 3. 核心作品 — 宣纸展厅

### 3.1 色温

暖黄白，情绪：温润、质朴。

### 3.2 背景层次（由底到顶）

| 层 | 内容 | 实现方式 | 参数 |
|----|------|----------|------|
| L1 底色 | 暖白宣纸色 | `linear-gradient(135deg, #faf6f1, #f0e8df)` | 覆盖整个 section |
| L2 纸张纤维 | 宣纸纤维肌理 | CSS 内联 SVG 噪点纹理 | 4×4px 重复，3% 透明度 |
| L3 光影氛围 | 柔光渐变 | `radial-gradient` 从中心偏上辐射暖光 | 模拟展厅顶部灯光 |
| L4 窗花水印 | 大幅窗花纹样若隐若现 | SVG 镂空窗花 | 2-3% 透明度，固定定位，覆盖约 60% |
| L5 微动效 | 光影缓缓呼吸 | CSS `@keyframes` opacity 变化 | 周期 8s，0.03-0.08 透明度范围 |

### 3.3 与现有内容的关系

- 产品卡片 `bg-paper-light` + `border-paper-dark/60` 在宣纸底上有轻微浮起感
- 深色文字 `text-ink-base` 在浅暖色底上对比度充足
- `section` 容器的 `bg-transparent` 改为内联背景样式

### 3.4 实现方式

在 `<section>` 上通过 CSS `background` 多层叠加实现，所有背景通过 scoped style 或内联 style 管理。

## 4. 剪艺宣言 — 纸雕光影

### 4.1 色温

冷白，情绪：纯净、庄重。

### 4.2 背景层次（由底到顶）

| 层 | 内容 | 实现方式 | 参数 |
|----|------|----------|------|
| L1 底色 | 纯净白色渐变 | `linear-gradient(180deg, #fdfbf8, #f8f4ee)` | 微妙冷暖过渡 |
| L2 纸张质感 | 手工纸肌理 | CSS 噪点 SVG | 2×2px 重复，2% 透明度 |
| L3 光影投射 | 阳光穿透效果 | `radial-gradient` 从顶部偏右投暖光 | 模拟自然光 |
| L4 窗花投影 | 镂空窗花的影子 | SVG 窗花纹样 | `rgba(0,0,0,0.04)` + `filter: blur(2px)` |
| L5 窗花浮层 | 窗花本体若隐若现 | 同一 SVG 偏移 4-6px | `rgba(0,0,0,0.03)` 透明度，与投影形成光影错位 |
| L6 微动效 | 光影缓缓移动 | CSS `@keyframes` translate | 投影层 ±3px 位移，周期 12s |

### 4.3 与现有内容的关系

- 现有 `<div class="absolute inset-0 z-0">` 内的 Unsplash 森林图和 `bg-forest-overlay/55` 完全移除
- 宣言文字 `text-mist-base`（浅色）需改为深色 `text-ink-base` 以适配浅色背景
- 定位方式保持 `relative`，文字层 `z-10` 不变

### 4.4 窗花 SVG 设计

- **来源：** 新设计一个对称的团花/窗花 SVG 矢量纹样，作为 `src/assets/wing-flower-pattern.svg` 引入
- **纹样选择：** 使用对称的团花纹样，与"雕琢大千世界"的主题呼应，包含常见的锯齿、月牙、柳叶等剪纸基础纹样
- **SVG 规格：** viewBox 800×800，单色填充（黑色），镂空部分为 transparent
- **放置方式：** 固定定位（`position: absolute`），居中偏上，覆盖约 60% 区域

## 5. 剪艺应用 — 锦缎织造

### 5.1 色温

暖金白，情绪：华贵、精致。

### 5.2 背景层次（由底到顶）

| 层 | 内容 | 实现方式 | 参数 |
|----|------|----------|------|
| L1 底色 | 浅香槟金到暖米渐变 | `linear-gradient(135deg, #faf5ed, #f5ede0)` | 覆盖整个 section |
| L2 编织纹理 | 织锦交叉纹 | CSS `repeating-linear-gradient` 交叉 45°/135° | `rgba(180,150,100,0.06)` 金色细线 |
| L3 金色丝线 | 织金装饰线 | SVG 曲线纹样 | `#c9a96e` 4% 透明度 |
| L4 浮动光点 | 丝线闪烁微光 | CSS 小圆点 + `@keyframes` 浮动 | `rgba(201,169,110,0.15)`，6-8 个光点 |
| L5 柔和网格 | 辅助秩序线 | 细线网格 | `rgba(180,150,100,0.04)` |

### 5.3 与现有内容的关系

- 设备展示（LaptopAnimation/PhoneAnimation）在锦缎底上有"丝绸展台"的高级感
- 现有 `bg-gradient-to-t from-evasion-sand/10` 设备光晕可保留，与锦缎底色融合
- 标题 `text-ink-base` 需检查对比度，必要时微调
- 纹样库区域的 `border-t border-paper-dark/40` 分隔线保留

### 5.4 浮动光点实现

```css
@keyframes float {
  0%, 100% { transform: translateY(0) translateX(0); opacity: 0.15; }
  50% { transform: translateY(-20px) translateX(10px); opacity: 0.25; }
}
```

每个光点使用不同的 `animation-delay` 和 `animation-duration`（6-10s 范围内随机），避免同步感。

## 6. 区域过渡设计

### 6.1 色温节奏

| 区域 | 色温 | 情绪 |
|------|------|------|
| 核心作品 | 暖黄白 (#faf6f1) | 温润、质朴 |
| 剪艺宣言 | 冷白 (#fdfbf8) | 纯净、庄重 |
| 剪艺应用 | 暖金白 (#faf5ed) | 华贵、精致 |

### 6.2 过渡方式

- 现有 `section-divider` 分隔线保留
- 三个区域均为浅色系，过渡自然，无需额外渐变过渡带
- 区域间通过底色的微妙色温差（暖黄 → 冷白 → 暖金）实现"移步换景"
