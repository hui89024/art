## 🎯 设计特点

### 视觉层次
1. **深色背景**：营造沉浸感和高级感
2. **金色点缀**：突出重点，增强装饰性
3. **传统纹样**：融入剪纸元素，强化文化属性
4. **层次分明**：通过阴影、边框、光晕建立视觉层次

### 动效设计
1. **视差滚动**：Hero区域的多层视差效果
2. **入场动画**：卡片和特性的错峰入场
3. **悬浮效果**：卡片上浮 + 金光扫过
4. **粒子动画**：20个金色粒子漂浮
5. **装饰动画**：线条延伸、光晕脉冲

### 装饰元素
1. **印章**：传统印章样式的标签和装饰
2. **云纹**：章节分隔使用传统云纹图案
3. **边角装饰**：卡片四角的装饰性边框
4. **装饰线条**：金色线条和菱形元素
5. **纹样背景**：淡淡的剪纸纹样水印

## ♿ 无障碍支持

1. **动画控制**：尊重 `prefers-reduced-motion` 设置
2. **键盘导航**：所有交互元素可键盘访问
3. **对比度**：文字对比度 ≥4.5:1
4. **语义化**：使用正确的HTML标签
5. **装饰元素**：添加 `aria-hidden="true"`

## 📊 性能优化

1. **GPU加速**：使用 `transform` 和 `opacity` 进行动画
2. **懒加载**：图片使用懒加载
3. **条件渲染**：移动端禁用部分动画
4. **防抖节流**：滚动事件使用 `passive` 监听
5. **WebP格式**：建议图片转换为WebP格式
